# Luby_assistent

## Descricao

A luby Assistent funcionara como um assistente virtual conversacional com foco a um publico alvo especifico. Desenvolvida com React, Node.js, Prisma, Docker.

## funcionalidades

- [ ] conversacao fluida
- [ ] leitor/scanner de arquivos (pdf,...)

## Arquitetura

luby_assistent/
|-backend/ #API REST
|-frontend/ #Client
|-.gitignore
|-docker-compose.yml
|-README.md

## Como rodar

git clone <github.com/fernandocostamabundadev/luby_assistent.git>

### Backend

cd backend
npm i
cp .env.example .env
npm run dev

### Frontend

cd frontend
npm i
cp .env.example .env
npm run dev
